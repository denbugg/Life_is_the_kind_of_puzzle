## Как читать метрики

Primary metric в этом документе — **direct exact tile-position accuracy**:
доля tile identities, поставленных в их абсолютные клетки. Для случайной
биекции:

`P(correct slot) = 1/576 = 0.00173611 = 0.173611%`,

то есть математическое ожидание равно **ровно одному правильному фрагменту на
доску**. Значения порядка `0.1–0.3%` сами по себе не означают практически
решённую раскладку.

Другие столбцы — только вспомогательные:

- `aligned` разрешает общую трансляцию раскладки и потому легче direct;
- `adjacency` — доля правильных направленных right/down bonds из 1104;
- edge `R@1/R@k` измеряет локальный поиск соседа, а не итоговую раскладку;
- SSIM смешивает геометрию и pixel quality и не заменяет identity accuracy.

### Критический caveat по truth

На текущих dirty boards layout labels восстанавливаются с доступом к clean
target через Hungarian (`candidate_supply.recover_layout`). Это полезный
target-assisted diagnostic, но **не сохранённая организаторами истинная
перестановка** и может содержать label noise. `trusted` — более лёгкая и более
надёжная часть тех же target-assisted labels; она недоступна на test. Поэтому
межсерийный рейтинг допустим только на одном matched panel. Source-disjoint
synthetic puzzles с известной перестановкой имеют более строгий exact truth.

## Самые перспективные направления

1. **Materially different global use of relation evidence.** Реальный
   component-pair signal и cross-query confidence подтверждены, но max-once
   existing-hard-edge ordering + cyclic5 не конвертировался в fresh exact.
   Возвращаться только к formulation, где relations jointly задают
   translation/cycle-consistent global structure; не делать nearby cap/bonus
   sweep текущего treatment.
2. **Объединить проверенные supply blocks.** Raw + full-resolution restored +
   contour/boundary modalities; новый no-downsample NAF уже добавляет d64 top32
   coverage `+4.857/+4.755 pp`, но fixed fusion регрессирует. Следующий шаг —
   context-aware selector/reranker, а не ещё одно fixed-alpha averaging.
3. **Pretrain representation, а не absolute grid head.** Взять P7
   corruption-invariant contrastive objective внутри более сильного
   Socket/full-tile encoder. Standalone E13 уже провалил bounded
   source-disjoint local gate и не является open-направлением.
4. **V30-style row/column/border unaries + LNS** использовать после более
   сильного context score, с новым CV и primary direct metric. Сам V30 не
   считать готовым default.
5. **E15** возвращать только как OOF study. Из **E20** переиспользовать лишь
   restored candidate emitter внутри materially new context-aware ranker;
   текущий residual ranker не продолжать. **Source retrieval** вести отдельным
   legal/compliance track, не смешивая с generic solver.

Рекомендуемый новый stack:

`multi-view raw-preserving supply → corruption-invariant side/full-tile encoder
→ component-conditioned graph Transformer → one-to-one V30-style LNS`.

Train/eval сначала на source-disjoint synthetic corruptions с известной точной
перестановкой. Real target-Hungarian labels использовать только как secondary
noisy diagnostic. Primary report обязан публиковать direct exact и число
правильных tiles/board; adjacency/aligned/SSIM — вторично.
