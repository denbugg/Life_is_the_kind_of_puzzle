### Legality и воспроизводимость TASKA

Сам generic layout path соответствует форме puzzle-решения:

- `src/infer_composed.py:199` описывает full 576-fragment bijection;
- `src/infer_composed.py:353-355` fail-closed отвергает duplicate tiles;
- validation в `src/infer_composed.py:806-845` сначала строит layout
  через `one(tiles)`, а затем читает clean target только для metric;
- layout индексирует исходные upright fragments; matcher views/restoration
  не подменяют tile identity.

Но ветка не содержит нужные `.pt/.npz` assets: `src/config.py`
указывает на external `E:/pazzle_work`, а journal — на Kaggle kernels.
Протокол также предшествует current source-disjoint roster/freeze audit.
Перед promotion нужно восстановить ровно generic solver, заморозить
все target-free scores/layouts и однократно переиграть его на current exact
source-disjoint panel.

Код: `src/verify_pair.py:82-104`, `src/train_verify.py:174-199` и
`src/train_verify_full.py:150-168` на `origin/TASKA-GOVNO-EBANOE@ae9d231ad4`.

| Record | Protocol | Result | Verdict |
|---|---|---|---|
| M465 | Focal verifier, 3020 train / 120 held, precision@430 | `.6481` init; `.6518,.6559,.6567,.6581,.6586,.6592,.6595,.6596` by epoch | Healthy convergence, но лишь `+.0115`, где нужно около `+.30`. |
| M466 | Matched square-off 24-board pipeline | placement `.0078→.0105`; adjacency `.2615→.2675` (`+.0060`, 1.5σ, 12/12); SSIM `.2660→.2676` | Ниже shipping `.2714` adjacency / `.2704` SSIM. |
| M467 | Same 400 boards, budget и architecture; focal vs absolute top-k hinge | init `.6420`; focal `.6344,.6431,.6451,.6443`; hinge `.4417,.4878,.4942,.5817` | **Reject.** Hinge рухнул и не вернул baseline. |

M467 использует detached k-th numeric threshold и fixed margin `1.0`:
каждый positive должен оказаться выше `threshold+1`, а каждый negative —
ниже `threshold-1`. Это двигает всю score distribution и ломает
zero-init calibration.

Текущий boundary pair-exchange в
`src/aiijc_puzzle/union_hard_edge_cutoff_loss.py` не является дублем:
он сравнивает только current `false selected × missed true` внутри
каждой axis через `softplus(s_false-s_true)`, без numeric threshold и
fixed margin. Он shift-invariant и сохраняет inherited residual L2 `1e-3`.
Повторять M467 нельзя; этот pair-exchange — отдельная гипотеза.

`164.031/1104` pairs и `1.875` exact в разрешённом protocol.

## Фиксированный следующий gate

Если возвращать TASKA, честный минимум — не смешивать её с новым
loss в первом запуске. Нужен один fixed comparator:

1. использовать только dirty-visible inputs; denoised pixels — matcher-only;
2. сохранить исходные upright tile identities и strict 0..575 permutation;
3. заморозить scores, edge order и layouts до чтения references;
4. один раз измерить fixed-top pairs, adjacency/1104 и exact tiles/board
   на source-disjoint exact synthetic panel;
5. не sweep-ить square weight, raw/margin order, floor, depth, temperature
   или selector threshold на открытом panel.

До этого TASKA остаётся самым важным несопоставленным historical
solver result, M467 — закрытым duplicate, а V32/V33 — не production evidence.
