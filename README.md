# Puzzle Check — локальный SSIM-скорер

Небольшой сайт для проверки ZIP-архива с результатами Puzzle Challenge. Он находит в архиве 18 известных тестовых изображений, сопоставляет их по имени с эталонами и считает средний SSIM.

Все изображения обрабатываются только в браузере и никуда не загружаются.

## Как запустить

Понадобится [Node.js](https://nodejs.org/) версии 20 или новее.

```bash
git clone --branch agent/ssim-scorer --single-branch https://github.com/fenix0501/pazzle_will_be_killed.git puzzle-ssim-scorer
cd puzzle-ssim-scorer
npm install
npm run dev
```

Откройте адрес, который напечатает Vite — обычно это [http://localhost:5173](http://localhost:5173).

## Как пользоваться

1. Подготовьте ZIP с результатами. Изображения должны быть в формате PNG и иметь исходные имена вида `img_000013.png`.
2. Перетащите ZIP в область загрузки или нажмите «выберите файл».
3. Дождитесь расчёта. Сайт покажет средний SSIM, число найденных/пропущенных файлов и оценку каждого изображения.
4. Выберите карточку изображения и двигайте разделитель, чтобы сравнить эталон с вашим результатом.

Вложенность папок внутри ZIP не важна: сопоставление выполняется по имени файла без пути. Файлы с неправильным размером или повреждённые изображения отмечаются отдельно и не попадают в среднее.

## Production-сборка

```bash
npm run build
npm run preview
```

Готовые статические файлы появятся в `dist/`.

## Формула

Реализация повторяет параметры:

```python
skimage.metrics.structural_similarity(
    image_true,
    image_test,
    channel_axis=2,
    data_range=255,
)
```

Используются окно 7×7, sample covariance correction и среднее по трём RGB-каналам. В итоговое среднее входят только найденные и корректно прочитанные изображения; количество пропусков и ошибок выводится отдельно.
