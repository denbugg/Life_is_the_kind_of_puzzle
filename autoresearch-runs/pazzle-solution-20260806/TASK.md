# Task

Build a concrete, excellent, reproducible solution for the PAZZLE image-restoration competition: reconstruct each 480x480 RGB image from 576 independently degraded and shuffled 20x20 tiles, then maximize mean RGB SSIM on 700 hidden test images. The known inputs are 7,000 paired train images and 700 test inputs; the hard unknown is a placement method whose gains survive end-to-end SSIM rather than only sampled edge-ranking metrics. This is an interactive autoresearch run: audit previous work, research diverse external methods, define mechanically falsifiable experiments, then execute and verify the strongest candidates against the real metric. The task admits many competing global-assembly, scoring, source-retrieval, and restoration hypotheses and therefore warrants a generational experiment search rather than a single speculative implementation.
