# Raw-image transformer research after user clarification`n`nThe new track must operate on RGB content of all 576 tiles from an individual image, not P12 scores, DINO cache features, source IDs, filenames or a tile-to-slot lookup. The first viable architecture is a two-stage visual transformer: a raw-RGB tile encoder (patchification inside each 20×20 tile) followed by a relational set transformer over all 576 tile tokens. Its losses should be adjacency/relative-offset prediction plus masked raw-pixel or latent reconstruction, with a doubly-stochastic assignment projection only at inference. This forces image-specific relational reasoning and avoids the rejected tile-only absolute-coordinate head.`n`nJPDVT directly conditions positional denoising on visual content and uses relative 2-D positional representations to avoid a trivial absolute-classifier solution. PuzLM demonstrates that global encoder-decoder reconstruction can avoid factorial permutation classification, but its token sequence is too long for an immediate 576-tile raw-image implementation on a 8 GB RTX 2070.
