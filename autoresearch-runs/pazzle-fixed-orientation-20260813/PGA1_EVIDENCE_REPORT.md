# PGA1 Evidence Report — Hierarchical Set-to-Slot Sinkhorn Assignment

**Experiment family:** ORBIT-24 PGA1  
**Date:** 2026-08-13  
**Status:** **Rejected before real-input DEV or production**

## Purpose

PGA1 tested the research-backed hypothesis that a permutation-equivariant Transformer could infer an entire 576-tile-to-576-slot bijection directly from the unordered, independently corrupted tile set. It used a shared tile stem, a set-attention block, learned/fixed 2-D slot queries, full 576×576 logits, log-Sinkhorn during training, and exact Hungarian decoding. This was deliberately different from F1 direct-pair routing, G1 coarse independent row/column labels, and G3 direct canvas regression.

The implementation used synthetic tiles generated by the existing audited distortion pipeline. Test images were not opened. The source-group manifest was deterministically pinned into **FIT=5,360**, **CAL=670**, **DEV=670**, plus **reserve=300**; all 7,000 known source groups are singleton groups, so split membership is group-disjoint under that manifest.

The smoke confirms that the proposed global permutation operation is mechanically valid and inexpensive enough. It is not a quality result.

## Relative-overfit controls

| Control | Training setup | Exact tile→slot top-1 | 6×6 macro membership | Synthetic raw SSIM | Synthetic assembled SSIM | Delta |
|---|---|---:|---:|---:|---:|---:|
| Stochastic corruption | 2 FIT boards, 600 steps; new per-tile corruption and input permutation each step | 40.19% | 54.17% | 0.1000 | 0.3762 | +0.2763 |
| Fixed-corruption control | Same 2 FIT boards, 1,200 steps; corruption fixed per board, input permutation still random | 11.55% | 25.87% | 0.1003 | 0.2540 | +0.1537 |

The second control is decisive for the intended capacity test: with fixed tile appearance but random input order, the model did **not** approach the pre-registered 95% exact-placement threshold. It therefore cannot be considered a trustworthy generalizable ordering model. The first result demonstrates only a non-random short-run signal, not a valid DEV result.

## Gate decision

The required relative-overfit gate was:

> Two FIT boards with random input permutation must reach tile→slot top-1 ≥ 95% before evaluating real-input DEV.

Both controls failed this gate (40.19% and 11.55%). The counterintuitive deterioration under the fixed-corruption control makes a full real-input source-disjoint DEV run scientifically unjustified: it would consume compute while testing an architecture that has not established basic learnability.

The user supplied **SSIM 0.2161981413457065** as the best historical comparable solution. Neither PGA1 synthetic score is compared to it: their targets and corruption protocol are diagnostic-only. PGA1 has not earned a real-input DEV evaluation and cannot claim any improvement over that benchmark.

## Decision and consequence

**Reject PGA1 v1.** Do not scale, do not run E26, and do not generate a submission from it. Retain the architecture result as evidence that a naive full slot-query Transformer is insufficient under this 24×24 independently corrupted regime. Any future Transformer family must introduce a distinct mechanism—e.g., multi-stage denoising of calibrated structural evidence, or clean-target conditional reconstruction that can pass a two-board capacity test—not merely deeper/wider PGA1 variants.
